# HR Employee System v3

Supabase-backed HR employee database and tracking system.

## Features
- Supabase email/password login
- Dashboard metrics
- Employees
- Companies: It's My Cake and Zayco Boga Alifa
- Contracts
- Leave requests
- Warnings / SP
- Master data
- Responsive layout

## Configuration
Edit `config.js` and set:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

Use only the public anon/publishable key in browser code. Never put a Supabase service-role key in this project.

## Deploy
This is a static site and can be deployed to Vercel, Netlify, or GitHub Pages. Vercel is recommended for the production URL.
